「烬序 JINSU」是美嘉拓旗下、面向竖屏短剧创作的 **纯浏览器** AI 全流程工作台：从剧本出发，完成分集剧本、实体设定、
分镜拆分、分镜生图、角色管理、AI 配音、视频生成、剪辑成片到导出的完整链路。

## 为什么选 JINSU —— 本地优先，不是口号

很多「AI 短剧」工具把你的剧本、角色、分镜素材上传到厂商云里黑盒处理（典型如 huobao 这类云依赖方案），
而另一些能本地部署的方案（如 Toonflow）又没有把「隐私 / 零云依赖」当成第一卖点。
**JINSU 把这些当成出厂设定，且已在开源版里全部实现——以前只是没在首屏喊出来：**

| 维度 | JINSU（开源版） | 黑盒云工具（如 huobao） | 其他本地方案（如 Toonflow） |
| --- | --- | --- | --- |
| 数据流向 | **全程本机，模型直连，数据不出本机** | 上传到厂商云、黑盒处理 | 可本地部署，但隐私非主打 |
| 账户体系 | **无账户、无会员、无积分** | 强制登录、按量付费 | 视部署方而定 |
| 模型归属 | **你自己的 Key，随时可换** | 锁死厂商模型 | 一般支持本地模型 |
| 配置成本 | **接模型只填三样**（见下） | 不用配但被绑定 | 需自行部署运维 |

**接模型只要三样，OpenAI 兼容：** 开源版不内置模型，但接入只需在你本机填
`Base URL` / `API Key` / `模型名` 三项——文本、图片、视频、配音、音乐、3D 全按这个走。
想要更强画质就接 **ComfyUI 自托管工作流**（见下），想要零运维就接任意云 API，
**选择权永远在你，数据永远不离开你的机器。**

## 特性

- **纯 Web 应用**：不依赖任何桌面壳，浏览器打开即用。
- **直连模型 API**：文本 / 图片 / 视频 / 配音 / 音乐 / 3D 全部由用户自行配置，
  不经过任何中间服务端。**接入只需填 `Base URL` / `API Key` / `模型名` 三样，全部 OpenAI 兼容。**
- **本地优先 / 数据不出本机**：项目、素材、生成结果默认只保存在本机浏览器存储中，
  模型调用也指向你自己的服务，无人替你保管数据。
- **ComfyUI 自托管**：可接入你自己的 ComfyUI 实例跑高质量生图 / 图生视频工作流，
  不依赖任何云端算力，本地即可完成最难的部分。
- **无账户体系**：不需要登录、没有会员与积分。

## 配置模型 API（必做）

开源版不内置任何模型服务。首次使用请打开 **设置 → 模型配置**，按模态填写：

| 模态 | 用途 |
| --- | --- |
| 文本 | 剧本生成、分镜拆分、提示词润色 |
| 图片 | 分镜生图、角色设定图 |
| 视频 | 图生视频 / 文生视频 |
| 配音 | TTS 语音合成 |
| 音乐 | 背景音乐生成 |
| 3D | 三维模型生成 |

每项需填 `Base URL`、`API Key`、`模型名`，接口遵循 OpenAI 兼容协议。
未配置时提交生成会给出明确提示。

### 可选：自建后端

少数能力（服务端抽帧、服务端合并导出）需要自建后端。若已部署，可在
**设置 → 模型配置** 中填写「后端服务地址」，或直接在浏览器控制台执行：

```js
localStorage.setItem('BACKEND_BASE_URL', 'https://your-backend.example.com')
```

未配置时这些功能不可用，其余能力不受影响。

## 目录结构

```
src/
  components/Studio/     # 主界面（外壳、工作区、流水线各步骤、设置）
  components/NewScript/  # 旧版短剧流程组件
  lib/providers/         # 统一模型接入层（按模态调用 OpenAI 兼容接口）
  lib/                   # 提示词模板、分镜、媒体工作流、ffmpeg 封装等
local-packages/          # 本地依赖包（ui / agnes-client / glm-client）
```

## 规划路线（Roadmap）

> 开源用户最买单的点 —— **本地优先 / 数据不出本机 / 接模型只填三样 / ComfyUI 自托管** —— 已在代码中实现，并前置到本页首屏。
> 以下为后续演进方向，按优先级推进。

- ✅ **第一优先 · 节点画布（react-flow）**：分镜段落 / 参考图 / 视频片段作为节点可视化排布，与线性「大纲模式」双视图切换。
  已在 `components/InfiniteCanvas/` 落地（支持从项目素材、分镜首帧 / 视频提示词一键导入为生成节点），不动现有生成逻辑，风险低。
- 🟡 **第二优先 · 一键全自动流水线（可选 Agent 模式）**：新增 `lib/pipeline/orchestrator.js` 编排器，把
  「剧本 → 艺术指导 → 资产 → 分镜 → 动态 → 装配 → 配音 → 混音 → 导出」用合理默认值自动连跑；
  但每一步允许手动覆盖 / 重跑，保留「分步可控」卖点。Agent 只做「建议默认值 + 异常兜底」，不剥夺用户控制权。
  复用 `lib/providers/` 模型接入层与现有各 step 提交函数。工作量：大（状态机 + Agent 编排）｜风险：中。
- 🟡 **第三优先 · 多轨剪辑台（ffmpeg.wasm）**：把「后端合成黑盒」换成浏览器内交互式多轨剪辑，对齐 reveric 的剪辑台。
  工作量：中｜ROI 不如第一、第二直接。
- ⚪ **远期 · 3D 导演台（three.js）**：理念值钱但 Web 端成本高（Flutter Scene 无对应）；建议等第一、第二验证后再评估，暂不碰。
